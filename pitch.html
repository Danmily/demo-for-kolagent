06 · 方案核心决定

把 Agent 拆成三个角色

张
老张数字分身 · AI

负责「关系」

用老张口吻说话、引用老张视频回答、记得每个粉丝、主动跟进、把重要的事转给本人

🤖
群助手 · 机器人

负责「工具」

签到、抽奖、组队、风控、活动查询。不需要人格，不消耗老张人设

张
老张本人

负责「关键时刻」

分身识别出高情感、高价值消息后升级，本人在后台一键亲自回复

为什么要拆？最初做的统一"群助手"越做越像客服——省了老张的时间，却没拉近粉丝和老张的距离。拆开后：工具归机器人，聊天归分身，最打动人的那一下留给本人。

① 入群识别

不增加门槛：档案分三层建立

L0 · 自动

粉丝什么都不用做

申请的群、群号来源（哪期视频简介）、口令是否答对

L1 · 可跳过

一道来意题

"你进群最想做什么？" 选了"找攻略答案" → 初判 核心粉候选 × 攻略需求型

L2 · 行为确认

在互动中逐步确认

提问被解答并致谢 → 确认 核心粉 × 攻略需求型。跳过 L1 也能推断

B 站授权是可选增强项、默认关闭。分流而非拒绝：只推荐更合适的群，不额外提高门槛。

② 分层承接

同一句话，不同粉丝由不同角色回应

消息意图普通 / 需求型核心粉舰长 / 铁粉
问开播 / 更新分身答分身答 + 预约分身答 + 专属预告
问攻略分身引用老张视频答同左同左，可优先进本人答疑
表达 / 提建议分身接话，按热度汇总汇总给老张升级本人高优队列
签到 / 组队 / 活动群助手处理
商务合作转商务队列

规则由 UP 主在「配置中心」点击切换，实时生效。分身无把握时不编造，转本人。

V3 深挖 · Personal Agent

每个粉丝，都有一个只属于他的「老张」

同一个老张人设，但对每个粉丝，分身拥有独立的记忆、独立的偏好、独立的关系进度。粉丝越用，它越懂你；老张越用，越知道该把自己的时间给谁。

V3 深挖 · 私有化定制

粉丝能定制，老张能定制，数据归粉丝

粉丝侧定制
  • 怎么称呼我（"旅行者" / 昵称）
  • 提醒什么、什么时候提醒、多久一次
  • 想聊的话题（只聊攻略 / 也聊日常）
  • 商业推荐开关
老张侧定制
  • 分身人设、语气、口头禅
  • 哪些粉丝 / 哪些时刻必须升级本人
  • 对舰长的专属话术与权益
  • 不允许分身代说的话题
私有化边界
  • 每个粉丝的记忆单独存储、互不共享
  • 粉丝可查看、导出、一键清除
  • 老张只看摘要和标签，看不到私聊原文
  • 退群即冻结，30 天后删除
